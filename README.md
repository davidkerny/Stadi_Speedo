MultiGauge od V1.8:

1. SPÍDO režim: (rychloměr) se ukazuje:
   pokud budík zaznamená jízdu.
   Pokud nějaké zaznamená, ukáže i celkově ujeté km, trip km, max. km/h, otáčky motoru.
   Při rychlejší jízdě radši skryje zbytečnosti.
3. TACHO režim (otáčkoměr)
   pokud zaznamenává otáčky motoru, ale ještě nikdy "nejel". Rpm + max. rpm.
4. Rev Mode (dočasný otáčkoměr)
   pokud už moped jel a tůruješ ho na místě, ukáže otáčky, max. rpm + trip km.
